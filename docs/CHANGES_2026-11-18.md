# Changes of 2026-11-18: fixes from the 2026-11-17 audit

The audit (`docs/reviews/BACKTESTER_AUDIT_2026-11-17.md`) found no calculation errors, but three problems with how
results could be read and used: verdicts drifted silently as data was added, reports hid how far trades fell before
they recovered, and nothing could test the research app's regime and context information. This change log says
what was done about each, in the order it was done, with the state before and after.

Commits: 43f0869 (code and registration, before any run on real prices), 40ad5e1 (study window), and the commit
holding this file (the first runs and the docs). 53 tests pass (36 before, 17 new).

## Order, and why this order

1. **Read the existing evidence honestly first** (descriptive only, no verdict can change): verdict-change list, risk
   inside trades, 90% intervals. Checked by rebuilding the last recorded runs: 0 differences.
2. **Stop silent drift**: Lead v3, a fixed development window and a separate forward record. A new verdict version, so
   it was registered in `rule_lock.json` and committed before it ran on real prices.
3. **Test the open questions instead of guessing**: the filter tests (ideas 7 and 8, the VIX curve, release days) and a
   volatility-matched baseline, registered before any ran.
4. **Price the instrument actually considered for leverage**: the same trades in TQQQ and UPRO.
5. **Give the research app something richer to show**: one evidence card per strategy.
6. **Found while running**: the indicator studies drifted the same way; fixed with the same window (method 3).

Not done here: the research app's side (its own chat; see the end), and items the audit ranked optional.

## Residual limits found while fixing

- **Vendor noise at exact boundaries.** Each Yahoo re-download moves adjusted prices by about one part per million,
  which flips two knife-edge "close above the 5-day average" exits back and forth (QQQ signal 2013-12-12: exit 12-16
  or 12-17; SPY signal 1993-07-22: 07-23 or 07-26). The fixed window cannot stop this; it moves QQQ RSI(2)'s p by about
  0.0005 between downloads. The verdict-change list now shows any flip it causes. The audit's suggestion to round to
  the cent was wrong for adjusted history (old adjusted prices are not in cents); a comparison tolerance would be a new
  rule version and was not made.
- `exit_next_open` for a development trade that exits on 2026-11-13 uses the following open (2026-11-16). Descriptive.
- 1993-2009 has no interval or risk measures: its statistics were stored before these existed, and computing them now
  would be a second look.
- The first v3 trade run and the first filter-test run were made at 43f0869, before the method number moved to 3;
  their records say method 2, though their windows are fixed (`verdict_version` v3 and `development_end` say so).
